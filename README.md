# JavaScript Assignment

This repository contains my JavaScript assignment which includes multiple programming tasks and a dynamic countdown timer built using HTML, CSS and JavaScript.

## Tasks

### Task 1 – Second Largest Number
Write a JavaScript program to find the second largest number from the array:

[23, 45, 67, 89, 12, 90, 44]

The solution finds the second largest number without sorting the array.

---

### Task 2 – Unique Elements from Two Arrays
A function is created that takes two arrays as input and returns a new array containing only the unique elements from both arrays.

Example arrays used:
[1, 2, 3, 4]  
[3, 4, 5, 6]

---

### Task 3 – Student Score Analysis
An array of student objects is used containing name, age and scores.

The program:
- Calculates the average score for each student
- Identifies the student with the highest average score
- Displays the top student in the console

---

### Task 4 – Countdown Timer
A one hour countdown timer is implemented using HTML, CSS and JavaScript.

Features:
- Start button
- Pause button
- Reset button
- Time displayed in **MM:SS format**
- Prevents negative countdown
- Displays a message when the timer reaches zero
